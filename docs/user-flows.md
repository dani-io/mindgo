# User Flows — پلتفرم کوچینگ و توسعه فردی

**نسخه:** ۱.۰  
**مرجع:** PRD v1.0

---

## فلوی ۱: مسیر رهجو (Client Journey)

### A. Onboarding (ورود اولیه)

```
Landing Page → OTP Login (Phone + Code) → 3 Golden Questions → Dashboard
```

1. **Landing Page:** صفحه ورود با معرفی کوتاه پلتفرم
2. **OTP Login:** ورود شماره موبایل → دریافت کد از کاوه‌نگار (Pattern Method) → تأیید کد
3. **۳ سوال طلایی:** Progressive Profiling — فقط ۳ سوال اصلی. بقیه بعداً.
4. **Dashboard:** ورود به داشبورد رشد. آماده کاوش.

### B. پیدا کردن راه‌بلد و رزرو

```
Marketplace (Browse + Filter) → Coach Profile → Select Package → Pick Time Slot
```

5. **مارکت‌پلیس:** لیست راه‌بلدها + فیلتر بر اساس تخصص، جنسیت پذیرش، امتیاز
6. **پروفایل کوچ:** بیوگرافی + تگ‌ها + جعبه ابزار اعتماد (مدارک) + صدای راه‌بلد (Voice Intro) + نظرات
7. **انتخاب پکیج:** جلسه معارفه (تکی) یا پکیج چند جلسه‌ای
8. **انتخاب زمان:** تقویم شمسی + اسلات‌های آزاد کوچ (فیلتر شده بر اساس Google Calendar sync)

### C. پرداخت و جلسه

```
Payment (ZarinPal / SnappPay) → Escrow Lock → SMS Reminder (30 min) → Jitsi Session
```

9. **پرداخت:** انتخاب روش (نقدی: زرین‌پال / اقساطی: اسنپ‌پی)
10. **قفل Escrow:** سهم کوچ (۷۰٪) در وضعیت «قفل شده» قرار می‌گیرد
11. **یادآوری پیامکی:** ۳۰ دقیقه قبل از جلسه به هر دو طرف ارسال می‌شود + لینک Jitsi
12. **جلسه آنلاین:** ورود به اتاق Jitsi از درون وب‌اپلیکیشن (دکمه ۳۰ دقیقه قبل فعال)

### D. بعد از جلسه

```
Confirm Session (or auto 24h) → Coach Share Freed → Rate + Review → Next Session
```

13. **تأیید جلسه:** رهجو تأیید می‌کند که جلسه برگزار شده. اگر ۲۴ ساعت پاسخ ندهد، خودکار تأیید.
14. **آزادسازی سهم:** سهم آن جلسه از «قفل» به «قابل برداشت» در کیف پول کوچ منتقل می‌شود.
15. **امتیازدهی و نظر:** رهجو می‌تواند به صورت اختیاری نظر بدهد (با نام کوچک یا ناشناس).
16. **جلسه بعدی:** اگر پکیج چند جلسه‌ای خریده، برمی‌گردد به مرحله ۸ (انتخاب زمان).

### نقاط تصمیم (Decision Points)

| نقطه | شرط | مسیر A | مسیر B |
|---|---|---|---|
| مرحله ۷ | کاربر جدید؟ | جلسه معارفه ارزان | پکیج چند جلسه‌ای |
| مرحله ۹ | روش پرداخت | زرین‌پال (نقدی) | اسنپ‌پی (اقساطی) |
| مرحله ۱۳ | تأیید رهجو | دستی (کلیک) | خودکار (۲۴ ساعت) |
| مرحله ۱۵ | رضایت | نظر مثبت | شکایت → اتاق داوری |

## فلوی ۲: مسیر راه‌بلد (Coach Journey)

### A. ثبت‌نام و تأیید

```
Sign Up → Complete Profile → Upload Certs → Voice Intro → Submit → Admin Review → Approved/Rejected
```

1. **ثبت‌نام:** شماره موبایل + اطلاعات پایه
2. **تکمیل پروفایل:** بیوگرافی کوتاه + تفصیلی + تگ‌های تخصص + فیلتر جنسیت پذیرش
3. **آپلود مدارک:** تصاویر سرتیفیکیت‌ها (ICF، موسسات داخلی) + عنوان + سال
4. **Voice Intro:** ضبط فایل صوتی حداکثر ۲ دقیقه‌ای (معرفی + خوش‌آمدگویی)
5. **ارسال برای بررسی:** وضعیت: «در انتظار تأیید»
6. **بررسی ادمین:** مدیر پشتیبانی یا مدیر ارشد مدارک و صدا را بررسی می‌کند
7. **نتیجه:**
   - ✅ تأیید → تیک سبز اعطا می‌شود → پروفایل فعال در مارکت‌پلیس
   - ❌ رد → دلیل رد از طریق پیامک به کوچ ارسال → امکان ویرایش و ارسال مجدد

### B. عملیات روزانه

```
Set Availability → Sync Calendar → Get Booking (SMS) → Run Session (Jitsi)
```

8. **تعریف زمان‌بندی:** روزها و ساعات آزاد (مثلاً شنبه و دوشنبه ۱۶-۲۰)
9. **سینک تقویم:** اتصال Google Calendar / Outlook → غیرفعال شدن خودکار اسلات‌ها
10. **دریافت رزرو:** پیامک اطلاع‌رسانی + نمایش در داشبورد
11. **برگزاری جلسه:** ورود به اتاق Jitsi + چت با رهجو + ارسال تمرینات

### C. مالی

```
Session Confirmed → Wallet Grows → Request Payout (min 500K) → Monday Transfer (Paya)
```

12. **تأیید جلسه:** سهم آن جلسه از «قفل» آزاد می‌شود
13. **رشد کیف پول:** با هر جلسه تأیید شده، موجودی قابل برداشت افزایش می‌یابد
14. **درخواست تسویه:** حداقل ۵۰۰ هزار تومان → ثبت درخواست
15. **واریز دوشنبه:** لیست پایا دسته‌جمعی به بانک ارسال می‌شود

### مسیر جایگزین: افزودن دستی توسط ادمین

```
Admin creates coach → Pre-fills profile → Coach completes remaining fields → Auto-approved
```

## فلوی ۳: مسیر ادمین (Admin Operations)

### A. مدیریت راه‌بلدها

```
Onboarding Queue → Review Docs + Voice + Bio → Approve (Green Badge) / Reject (Send Reason)
```

1. **صف تأیید:** لیست کوچ‌های جدید با وضعیت «در انتظار»
2. **بررسی:** مشاهده مدارک + گوش دادن به Voice Intro + خواندن بیوگرافی
3. **تصمیم:** تأیید (تیک سبز) یا رد (با ذکر دلیل)

### B. عملیات مالی

```
View Wallets (Locked vs Available) → Review Payout Requests (SHEBA) → Export Paya (Excel) → Batch Transfer
```

4. **مشاهده کیف پول‌ها:** موجودی کل، قفل شده، قابل برداشت هر کوچ
5. **بررسی درخواست‌های تسویه:** شماره شبا + نام صاحب حساب
6. **خروجی پایا:** فایل اکسل/متنی برای واریز بانکی
7. **واریز دسته‌جمعی:** ارسال لیست پایا هر دوشنبه

### C. داوری و پشتیبانی

```
Session Disputes → Investigate (Check Status) → Rule for Client (Refund) / Rule for Coach (Release Share)
```

8. **شکایات جلسات:** لیست تیکت‌های باز (شکایت رهجو یا کوچ)
9. **بررسی:** چک وضعیت جلسه (برگزار شده / کنسل / غیبت)
10. **حکم:**
    - به نفع رهجو: بازگشت وجه (Refund) + سوزاندن سهم قفل شده کوچ
    - به نفع کوچ: آزادسازی سهم قفل شده

### D. نظارت عمومی

```
Support Tickets (Chat + FAQ) → Community Moderation → Create Challenges → Analytics Dashboard
```

11. **تیکت‌های پشتیبانی:** پاسخ به چت‌ها + مدیریت FAQ
12. **مادریشن قبیله:** حذف کارت‌های نامناسب
13. **ایجاد چالش:** تعریف چالش‌های گروهی جدید
14. **داشبورد آماری:** تعداد کاربران، جلسات، درآمد

### ماتریس دسترسی (RBAC)

| عملیات | Super Admin | Support Manager | Support Agent |
|---|:---:|:---:|:---:|
| تأیید/رد کوچ | ✅ | ✅ | ❌ |
| تسویه حساب / پایا | ✅ | ❌ | ❌ |
| داوری جلسات / Refund | ✅ | ✅ | ❌ |
| پاسخ چت / تیکت | ✅ | ✅ | ✅ |
| مادریشن قبیله | ✅ | ✅ | ✅ |
| تنظیمات پلتفرم | ✅ | ❌ | ❌ |
| مشاهده شبا / مالی کلان | ✅ | ❌ | ❌ |
| افزودن کارمند | ✅ | ❌ | ❌ |
